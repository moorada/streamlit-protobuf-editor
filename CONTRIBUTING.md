# Contributing

Bug reports and pull requests are welcome.

1. Fork the repository and create a focused branch.
2. Make the change and add or update tests where appropriate.
3. Run `./gradlew clean test jar` (`gradlew.bat` on Windows).
4. Open a pull request describing the problem and the solution.

Please keep source code, documentation, commit messages, and issue content in
English. Only test fixtures that specifically verify character encoding may
contain other languages.
